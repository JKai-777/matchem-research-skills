# 检索记录模板

复制后逐项填写，一次检索一个区块。不要覆盖旧记录。

```
## 检索 #1

- 数据库：
- 检索式：
  ```
  （完整布尔式，含字段标签，例如 TS=(...) AND PY=(2018-2025)）
  ```
- 检索日期：YYYY-MM-DD
- 限定条件：年份 / 文献类型 / 语言
- 初检数：
- 去重后：
- 入选数：
- 排除记录：
  - 不符材料体系：n 篇（编号…）
  - 无定量性能数据：n 篇
  - 综述或非原始研究：n 篇
  - 无法获取全文：n 篇
- 备注：检索式调整过的，写清这一版改了什么、为什么改
```

## 关键数据表（配套用）

| 材料体系 | 方法/工艺 | 性能指标 | 数值 | 单位 | 可比条件 | 出处 |
|---|---|---|---|---|---|---|

可比条件至少写四项：温度、介质（电解液/气氛）、驱动力（电流密度/倍率/压力）、样品形态。

原文缺的写"原文未给"。
