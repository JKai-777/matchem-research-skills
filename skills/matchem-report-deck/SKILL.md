# PPT 环：把思路变成能照着讲的页面

页面上的字是要念出口的，不是给人默读的。讲稿一律进 notes，页面上不放讲稿提示。

## 流程（顺序不可颠倒）

### 1. 定场景

场景决定详略，选错就白做：

- 组会：重方法细节——合成参数、表征条件、失败样本
- 导师汇报：重取舍理由——为什么这条路线、放弃了什么
- 基金 / 开题：重 gap 与创新点的对应关系
- 答辩：重结论与适用边界——什么条件下成立、什么条件下不成立

### 2. 出大纲，一页一论点

每页一行，写论点不写章节名：

- 合格："三条路线里选 A，因为 A 的判据两周内可测"
- 不合格："技术路线"——这是章节名，不是论点

大纲必须先给用户确认，确认后再成稿。

### 3. 成稿：正文 12 页上下，宁少勿多

参考骨架：

| 页 | 内容 |
|---|---|
| 1 | 封面：题目 / 汇报人 / 场景 / 日期 |
| 2 | 问题与 gap：一句 gap + 一张支撑图 |
| 3 | 科学假设：可证伪的一句话 + 判据 |
| 4-5 | 技术路线对比：互斥点、取舍理由 |
| 6-7 | 实验设计与对照组 |
| 8-9 | 预期结果与判据（含失败判据） |
| 10 | 风险与 Plan B |
| 11 | 时间节点与里程碑 |
| 12 | 参考文献 |

### 4. 写 notes

每页 3 至 6 句口语，含过渡句。讲稿只进 notes，页面上一个字都不放。

## 数据与引用规范

- 所有性能数值带单位，并写清测试条件：方法、温度、电解液、压力、倍率
- 不可比的数据不得放在同一张图里比较；无法避免时在页脚注明"条件不同，仅示意"
- 原文未给的条件写"原文未给"，不推断、不凑整、不换算
- 材料命名与表征手段写全称：X 射线衍射（XRD）、扫描电子显微镜（SEM）、电化学阻抗谱（EIS）
- 参考文献页每条必须可溯源，格式固定：
  ```
  [1] 完整题目. 前 3 位作者 et al. 期刊全名, 年份, 卷(期): 起止页. DOI: xxx
  ```
- DOI 照抄原件，形式可疑也在旁边标"待核"
- 图表来源必须标：自己测的写"本工作"，取自文献的标编号

## 交付前必做

- 跑版式校验：越界、文字溢出容器、元素重叠，拿到清单逐条修
- 逐页渲染成图自己看一遍：标题是否与论点一致、数字是否带单位、有没有残留占位文字
- 修订只基于用户改过的最新版本，不拿早期版本覆盖
- 不宣称"应该没问题"。没跑校验、没看过渲染图，就还没做完

## 禁忌

- 页面上不放"此处展开讲""讲稿提示"这类给自己看的话
- 不用"显著提升""效果良好"代替数值
- 不把未经核实的推断写进结论页
- 不为了凑页数加过渡页和目录页
