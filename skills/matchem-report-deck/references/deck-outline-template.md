# 大纲模板（一页一论点）

先填这张表，确认后再动手做页面。论点列写不出来的页，删掉。

| 页 | 论点（一句话，可念出口） | 支撑材料 | 讲稿要点（3-6 句，进 notes） |
|---|---|---|---|
| 1 | 封面：题目 + 场景 + 日期 | — | 自我介绍一句，说明本次要回答的问题 |
| 2 | 现有工作在 ___ 上是一片空白，具体是 ___ | 一张图或一张表，标注出处 | |
| 3 | 假设：若 ___ 则 ___，判据是 ___ | 机理示意图 | |
| 4 | 路线 A 与路线 B 在 ___ 上预测相反，做 ___ 就能分开 | 对比表 | |
| 5 | 选 A，因为 ___；若 ___ 出现则转 B | 周期/成本/成功率对比 | |
| 6 | 实验设计：___，关键是 ___ | 流程图 | |
| 7 | 对照组齐全，缺 ___ 则结论不成立 | 对照表 | |
| 8 | 预期结果：达标线是 ___（带单位与条件） | 预期曲线（标明是预期） | |
| 9 | 失败判据：若 ___ 则假设不成立 | — | |
| 10 | 主要风险是 ___，Plan B 是 ___ | 风险表 | |
| 11 | 里程碑：___ 前完成 ___ | 甘特图 | |
| 12 | 参考文献 | 按格式列全 | |

## 检查

- 正文页数 10 至 14，超出就砍
- 每页只有一个论点，标题就是论点本身
- 预期数据页必须标"预期"，不得画得跟实测一样
- 没有目录页、没有过渡页、没有致谢页
