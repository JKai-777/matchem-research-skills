# 对照组自查表

方案定稿前逐条过一遍。任一条答不上来，就补上再往下走。

## 通用四项

| 对照组 | 目的 | 缺失后果 | 本方案是否有 |
|---|---|---|---|
| 空白对照（不施加调控） | 证明效应来自调控手段 | 无法排除"本来就这样" | |
| 商业/文献基准样（同条件重测） | 建立横向可比基线 | 性能数字无法与文献对话 | |
| 变量隔离组（只改一个参数） | 定位因果 | 多因素同时变，结论不可归因 | |
| 重复样（n≥3，报离散度） | 判断差异是否超出噪声 | 差异可能在误差棒内 | |

## 按手段追加

**掺杂 / 固溶**
- 未掺杂基体
- 物理混合样（同名义配比但不进入晶格）→ 排除"只是混了第二相"
- 不同掺杂量的梯度系列 → 证明存在最优值而非单调

**表面包覆 / 异质结**
- 未包覆样
- 同质量分数的机械混合样
- 包覆前后比表面积（BET）→ 排除"只是面积变大"

**形貌 / 纳米化**
- 同成分微米级对照
- 归一化到比表面积后的性能对比 → 这一步不做，审稿人一定会问

**缺陷 / 空位工程**
- 未处理母体
- 处理但未引入目标缺陷的样（如只退火不还原）
- 定量缺陷浓度的手段（EPR、XPS 峰面积比、热重）→ 否则"缺陷"只是假设

**催化 / 电化学机理**
- 无催化剂的空白电极
- 中毒实验或清除剂实验 → 区分真实活性与背景

## 写进方案的一句话

对照组不是附录里的补充实验，是证明链条的一部分。方案正文里要写明：缺哪一组，结论就只剩相关性而推不出因果。
