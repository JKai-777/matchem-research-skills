# 思路环：从 gap 到可执行方案

这一环是主战场。目标不是罗列方案，而是让评审看见你为什么选这条、放弃那条。

## 输入

必须有上一环的 gap 陈述和关键数据表。

如果 gap 不落在数据表的空缺处，退回重做文献环，不要硬接——拍脑袋想出来的 gap 撑不起后面所有论证。

## 输出结构（按序写，缺一项就是没做完）

### 1. 科学假设

一句话，可证伪。写法：

```
若 <调控手段> 改变 <结构/界面/电子结构量>，
则 <性能指标> 将 <方向> 变化，
判据为 <数值阈值 + 测试条件>。
```

反例（禁止这样写）："通过掺杂提升倍率性能"——没有机理中介，没有判据，也没法被证伪。

### 2. 至少两条互斥技术路线

每条给全七项：

- 核心手段与预期机理
- 关键实验步骤（3 至 6 步）
- 需要的表征手段与设备
- 预期周期与成本量级
- 风险点
- **取舍理由**：为什么这条值得做
- **判死条件**：出现什么结果时这条路线被放弃

"互斥"的意思是：两条路线对同一现象给出不同预测，做一组实验就能把两者分开。如果两条路线的结论永远同向，那它们不是两条路线，是同一条路线的两种说法。

### 3. 可行性风险清单

逐项标 高 / 中 / 低，并写缓解办法：

- 试剂可得性：是否受管控、是否需进口、有无替代品
- 表征手段：本组有无该设备、机时排队时长、送样周期、是否需破坏样品
- 合成重复性：文献值能否复现、是否需要手套箱或惰性气氛
- 周期：到第一个可用数据点要多久
- 成本：原料单价、耗材、机时费
- 安全与合规：危化品、废液处理、X 射线与激光防护

### 4. 对照组设计

写明缺哪一组会被审稿人抓住：

- 空白对照：不施加调控手段
- 商业或文献基准样：同条件重测，不能直接抄文献值
- 变量隔离组：只改一个参数，其余全同
- 掺杂或包覆类：未掺杂基体 + 物理混合样，用于排除"只是混了第二相"
- 界面效应类：同成分不同形貌或比表面积样，用于排除"只是面积变大"

### 5. 主动指出薄弱环节

写在方案最后，不要等评审问：

- 哪一步最可能失败，失败后的 Plan B 是什么
- 哪个结论只靠间接证据（例如只做了 XRD 就说掺杂进入晶格）
- 哪个指标缺可比条件，无法与文献直接对比

## 纪律

- 性能目标带单位与测试条件，不写"大幅提高循环寿命"这种话
- 引用文献结论必须带可核验出处；查不到就写"我的推断"
- 不生成实验原始数据。方案里出现的数值只能是设计目标或文献值，且必须标明是哪一种
- 不确定的地方直说，不掩饰

## 常见被拒点

- 只给一条路线，看起来在赌，不像在研究
- 没有商业基准样同条件重测，数据无法横向比较
- 假设与验证手段错配，例如想证晶格掺入却只做 SEM
- 对照组缺失，尤其是"只改了表面积"这条替代解释没被排除
